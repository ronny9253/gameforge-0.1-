# GameForge v0.1

Executable foundation for the GameForge ⭐ mobile casual game factory.

## First command

```bash
./tools/gameforge validate
```

The validator checks the project contracts before we build gameplay systems.

## Principle

GameForge is not the game. It is the reusable factory that produces the game.
